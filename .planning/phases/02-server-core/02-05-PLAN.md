The server shuts down when the test process exits (tokio::test cleanup).

    Write connect_ws(port: u16) async helper that calls tokio_tungstenite::connect_async(format!("ws://127.0.0.1:{}/ws", port)).await.unwrap() and returns the (SplitSink, SplitStream).

    Write send(sink, msg: &ClientMessage) helper: serializes msg and sends as Message::Text.
    Write recv(stream) -> ServerMessage helper: reads next frame with tokio::time::timeout(Duration::from_secs(3), stream.next()).await, panics with clear message if timeout or None.

    Write send_connect(sink, nick, team) helper that sends Connect and waits for Welcome, asserts welcome.assigned_nick is non-empty, returns (assigned_nick, assigned_team).

    Tests:

    1. two_clients_chat: spawn_test_server(); connect two clients; both send Connect (Red/Blue); client-A sends Say{text:"hello from A"}; call recv on client-B; assert ServerMessage::Message{data} where data.text=="hello from A".

    2. team_filter: spawn; connect client-A (Red), client-B (Blue); A sends SayTeam{text:"red only"}; recv_with_timeout on B should timeout (assert no message arrives within 1 second — use tokio::time::timeout(1s, recv(B)).await.is_err()); A itself should receive the SayTeam broadcast (recv on A: assert Message received with channel==Channel::Team).

    3. rate_limit: spawn; connect one client; connect with nick; send 11 Say messages in a loop; collect responses; assert at least one is ServerMessage::RateLimited.

    4. length_cap: spawn; connect client; send Say{text: "x".repeat(501)}; recv; assert ServerMessage::Error{reason} where reason contains "too long" (case-insensitive match).

    5. scrollback: spawn; connect client-A and send 3 Say messages; disconnect A (drop the connection); connect client-C; recv Welcome from C; assert welcome.scrollback.len() == 3.

    6. joined_left: spawn; connect client-A; after A's Welcome is received, connect client-B; client-A should receive JoinedLeft{joined:true,nickname: B's assigned nick}; disconnect B (drop); client-A should receive JoinedLeft{joined:false}.

    7. lag_disconnect: This test verifies NET-03. Spawn server with broadcast_capacity=4 and max_lag_disconnects=3 (use a config variant with small capacity). Connect a "slow" client that never reads from the WS (use connect_ws but never call recv). Connect a "fast" client that rapidly sends 20 Say messages (enough to overflow the capacity=4 ring 3 times). The slow client's underlying WS connection should be closed by the server within a few seconds. Assert: attempt recv on slow client's stream; it should return None or Err (closed) within 5 seconds.

    All tests should run independently — each calls spawn_test_server() to get a fresh port and fresh AppState. Use #[tokio::test] not #[test].
