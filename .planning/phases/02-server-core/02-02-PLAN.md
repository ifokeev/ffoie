## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client-supplied nickname → server nickname | Client's Connect.nickname is advisory; server normalizes and owns the canonical nick |
| broadcast ring → slow client | BroadcastEvent ring capacity 1024; lagged receivers get Err(RecvError::Lagged) — handled in ws.rs (plan 02-03) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-03 | Spoofing | nickname assignment | mitigate | Server owns canonical nick; client request is advisory; assign_nick enforces uniqueness |
| T-02-04 | Denial of Service | broadcast ring | mitigate | Capacity 1024; lagged-client disconnect after 3 consecutive Lagged errors (implemented in plan 02-03) |
