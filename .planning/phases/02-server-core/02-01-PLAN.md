<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env → Config | Operator-controlled process env feeds Config::from_env(); malformed values cause startup failure (acceptable: fail-fast) |
| TCP → /healthz | Public unauthenticated endpoint; discloses server uptime and connection count |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | GET /healthz | accept | Uptime and connection count are low-sensitivity ops data; chat is a public game server |
| T-02-02 | Denial of Service | TCP listener | accept | No auth on healthz; flood protection is OS-level SYN cookies; out of v1.1 scope |
| T-02-SC | Tampering | Cargo dep install | mitigate | slopcheck — all Phase 2 deps (axum, tokio, tower-http, tracing, dotenvy, parking_lot, fastrand) are established crates with millions of downloads; verify via crates.io before `cargo build` |
</threat_model>
