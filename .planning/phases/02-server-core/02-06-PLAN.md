    Complete Phase 2 server: axum WS on /ws, broadcast fan-out with team filter, nick/team assignment, rate limit (burst=10, refill=2/s), 500-byte cap, 50-message scrollback, /healthz, graceful shutdown via SIGTERM.

  <how-to-verify>
    1. Start the server:
       `cargo run -p ffoie-chat-server`
       Confirm log output: "Listening on 0.0.0.0:8080"

    2. Health check:
       `curl -s http://localhost:8080/healthz | jq .`
       Expected: {"status":"ok","uptime_seconds":N,"connections":0,"version":"v1.1"}

    3. Open TWO terminal windows, each running:
       `websocat ws://localhost:8080/ws`

    4. In terminal 1, send Connect as Red:
       `{"type":"connect","nickname":"PlayerRed","team":"red"}`
       Expected response: Welcome with assigned_nick (may be "PlayerRed" or "PlayerRed#NNNN"), motd, empty scrollback.

    5. In terminal 2, send Connect as Blue:
       `{"type":"connect","nickname":"PlayerBlue","team":"blue"}`
       Expected response in terminal 2: Welcome. Expected in terminal 1: JoinedLeft{joined:true}.

    6. Health check with 2 clients:
       `curl -s http://localhost:8080/healthz | jq .connections`
       Expected: 2

    7. All-chat test (terminal 1):
       `{"type":"say","text":"hello from red"}`
       Expected in terminal 2: Message{data:{from:"PlayerRed",channel:"all",text:"hello from red"}}

    8. Team-chat test (terminal 1 — Red team):
       `{"type":"say_team","text":"red team only"}`
       Expected in terminal 2 (Blue): NO new message arrives. Terminal 1 (Red) DOES see it.

    9. /who test (terminal 2):
       `{"type":"who"}`
       Expected: WhoList with both players listed.

    10. Rate limit test (terminal 1 — send 11 Say messages rapidly):
        Paste 11x `{"type":"say","text":"flood"}` in quick succession.
        Expected: At least one RateLimited response received in terminal 1.

    11. SIGTERM test:
        In a new terminal: `kill -TERM $(pgrep ffoie-chat-server)`
        Expected: Both websocat sessions close. Server logs "graceful shutdown complete". Server exits within 5 seconds.

    12. Third client scrollback test:
        Restart server. Connect client-A, send 5 Say messages, disconnect (Ctrl+C on websocat).
        Connect a new client-C.
        Expected: Welcome.scrollback contains the 5 messages.
  </how-to-verify>
