<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WS client → ws_handler | Untrusted inbound frames; any client can send arbitrary JSON |
| per-conn rate bucket → broadcast ring | Rate bucket guards the fan-out ring from single-client floods |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Denial of Service | broadcast ring saturation | mitigate | Token bucket burst=10 refill=2/s; excess dropped with RateLimited to sender only; no disconnect on rate limit |
| T-02-06 | Denial of Service | oversized message amplification | mitigate | 500-byte cap; Error sent to sender; message dropped before broadcast |
| T-02-07 | Denial of Service | lagged-client memory pinning | mitigate | lag_count tracked; disconnect after max_lag_disconnects (default 3) consecutive Lagged errors |
| T-02-08 | Spoofing | Connect before any message | mitigate | connected=false gate; non-Connect messages before Connect → Error + continue (no crash) |
| T-02-SC | Tampering | Cargo dep install | mitigate | No new deps in this plan — uses axum ws, tokio, uuid already present |
</threat_model>
