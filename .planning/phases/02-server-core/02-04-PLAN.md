    Update main.rs to implement graceful shutdown with JoinSet tracking. Changes: (1) Add a tokio::task::JoinSet<()> stored in an Arc<parking_lot::Mutex<JoinSet<()>>> on AppState (or managed locally in main — simpler: manage the JoinSet in main alongside the serve loop). Since ws_handler is called by axum and spawns each connection implicitly via on_upgrade, we need a pattern that lets main track WS tasks. Use the following: extend AppState with a task_tracker: Arc<parking_lot::Mutex<Vec<tokio::task::JoinHandle<()>>>> field that ws.rs uses when spawning the handle_socket task — instead of axum's implicit spawn, explicitly call tokio::spawn(handle_socket(socket, state.clone())) inside ws_handler and store the JoinHandle. (2) In main(), after creating AppState, spawn a signal-listener task: tokio::spawn(async move { let token = state_clone.cancellation_token.clone(); #[cfg(unix)] { let mut sigterm = tokio::signal::unix::signal(tokio::signal::unix::SignalKind::terminate()).unwrap(); tokio::select! { _ = sigterm.recv() => {}, _ = tokio::signal::ctrl_c() => {}, } } #[cfg(not(unix))] { tokio::signal::ctrl_c().await.ok(); } tracing::info!("shutdown signal received — cancelling tasks"); token.cancel(); }). (3) Replace axum::serve(listener, app).await with axum::serve(listener, app).with_graceful_shutdown(state.cancellation_token.clone().cancelled_owned()).await.unwrap(). (4) After the serve future completes, wait for all tracked JoinHandles with a 5-second timeout: let deadline = tokio::time::Instant::now() + Duration::from_secs(5); for handle in state.task_tracker.lock().drain(..) { let remaining = deadline.saturating_duration_since(tokio::time::Instant::now()); if tokio::time::timeout(remaining, handle).await.is_err() { tracing::warn!("task did not finish within timeout"); } } tracing::info!("graceful shutdown complete"); (5) Ensure ws.rs explicitly stores the JoinHandle into state.task_tracker.lock().push(handle) — update ws_handler accordingly. (NOTE: if storing JoinHandles proves architecturally awkward, use tokio_util::task::TaskTracker instead — it has a wait() method with timeout support and is already pulled in via tokio-util. Prefer TaskTracker if it simplifies the code.) Log "graceful shutdown complete" before process exit.
